01 / WORKFLOW

Quick start

Start with a single representative sheet before processing a batch. That lets you check settings and output quality without waiting for every drawing.

01

Import a drawing

Open Home → Add drawings and select a PDF, PNG, or JPG. Multi-page PDFs are split into individual sheets, up to the 50-sheet batch limit. After import, answer the plot-scale and CAD-unit question for each sheet. Each answer controls 0.10-inch printed Simplex text; geometry still needs separate calibration.

HOME
02

Choose scan quality

In Convert, begin with 150 DPI and Automatic threshold. For faded or thin strokes, try Adaptive threshold or 200 DPI. Higher resolution needs more processing time.

CONVERT
03

Convert the sheet

Choose Home → Convert sheet, or Convert all for a batch. The app reconstructs raster linework in local processing tiles. Wait until the selected sheet reports Converted.

HOME

Review actual extracted geometry

Switch between Original, Overlay, and Vectors only. Inspect line connections, circle shapes, hatches, dimensions, small curves, and recognized line patterns.

REVIEW

03 / ACCURACY

Calibrate drawing scale

Scans are measured in pixels, not feet or meters. Calibration establishes how many drawing units each processed pixel represents.

  1. Select the correct sheet and enter the dimension value under Known distance.
  2. Choose its unit (feet, inches, meters, millimeters, or centimeters).
  3. Click Pick two points, zoom in, and click point A.
  4. Pan or zoom as necessary, then click point B. The app stores a scale for that sheet.
  5. Export and compare a second independent dimension in CAD.
Not georeferencing

Two-point calibration sets a measurement scale. It does not establish survey control, coordinate-system location, rotation, or real-world georeferencing.

04 / PRINTED ANNOTATIONS

Set each sheet’s plot scale and text size

Plot scale controls printed annotation size. Geometry calibration controls real model distances. You need both, and each sheet can have a different scale.

  1. After import, answer What is this sheet’s plot scale? for each new PDF page or image. Choose a common scale or Other — enter 1:n below, then select CAD drawing units.
  2. Choose Save sheet scale. The answer is saved only for that sheet, and its printed text height is set to 0.10 inches.
  3. Use Set later to defer an answer. Before export, return to Layers → Set sheet scale. A skipped answer is not silently treated as full size.
  4. Calibrate the drawing separately using Review & scale → Pick two points, then check an independent measurement.
Simplex text and dimension labels

Exported native/OCR text and recognized dimension labels use SIMPLEX, referencing simplex.shx. The DXF includes a matching default dimension style for future CAD dimensions. Detected dimension linework is still not an associative DIMENSION object. Browser text uses an approximate font.

Plot scale examples

For 0.10-inch printed height at 1″ = 20′, choose 1:240; model text height becomes 2 feet in a feet drawing. ¼″ = 1′-0″ uses 1:48. At 1:100 with millimeter CAD units, model text height becomes 254 mm. At 1:1 it is 0.10 inches, or 2.54 mm.

Changing an existing sheet

Edit Printed text height (inches) or Plot scale 1 : n under Layers and export again. Re-recognizing text is unnecessary for style changes. These are model-space heights calculated from your plot ratio, not annotative CAD text objects.

05 / MEASUREMENT QA

Recognize and validate dimensions

VecBuilt detects printed linear measurements from PDF text or local OCR, looks for a nearby dimension line with two witness/extension lines, and compares the measured geometry against the label after the sheet is calibrated.

01

Convert with OCR when needed

Scanned-image dimensions have no editable text layer. Keep Convert → Find dimensions during conversion enabled (on by default), then reconvert. Detection does not require exporting OCR text. Native PDF text can supply labels without OCR.

CONVERT
02

Calibrate from a trusted dimension

Set drawing units under Review & scale, and pick two endpoints for one reliable measurement. Do not validate the same reference dimension against its own calibration without an independent check.

CALIBRATE
03

Open Dimensions

Choose the Dimensions ribbon tab, then Find dimensions. The review drawer lists potential dimensions, automatically associated lines, mismatches, and measurements still needing endpoints.

RECOGNIZE
04

Review and correct

Select a note to center it in the viewport. Check the OCR reading, edit the printed value if necessary, or use Pick endpoints and click the two measured points directly in the drawing. You can also add a missing note manually.

REVIEW
05

Validate the difference

VecBuilt compares the printed dimension with the measured distance using the larger of percentage tolerance and minimum tolerance in drawing units. The default settings are 1% and 0.05 drawing units. These are initial review settings, not acceptance tolerances for all projects.

COMPARE
06

Export evidence

Download a dimension QA CSV or export a batch ZIP containing per-sheet dimension reports and a JSON manifest. Confirm review on each resolved measurement. A mismatch stays flagged after confirmation; it is not automatically corrected or approved.

REPORT
Rotated and uncertain OCR

Dimension OCR compares original and rule-suppressed images in horizontal and both vertical orientations. It accepts imperial fractions and trailing TYP/TYPICAL or a standalone ± mark. Numeric tolerances are not silently discarded. Check Original OCR in the selected finding. Missing foot marks may be inferred and flagged for review; digits can still be wrong. Inferred or low-confidence readings cannot trigger automatic dimension removal.

Important limitations

Association uses a recognizable baseline and two extension/witness lines. Continuous, label-interrupted, chained, and simple leader-offset dimensions are supported provisionally; not every callout or drafting convention will match. Elevations, stationing, radii and grid labels are not reliable linear dimensions. The feature does not create native associative DXF DIMENSION entities. A matching value is provisional until reviewed, and verified units and independent scale checks are essential.

06 / PROCESSING

Conversion settings

The Studio interface keeps advanced options under Convert → Advanced conversion. The classic interface shows more controls directly in the Convert tab.

Resolution

96 DPI is faster, 150 DPI is a good first pass, and 200–240 DPI can recover finer scan details. Higher settings increase processing time.

Threshold and noise

Adaptive threshold helps with faded or uneven backgrounds. Speckle removal cleans small isolated marks but can also erase tiny valid features.

Recognize circles

Attempts to fit real CAD CIRCLE entities to sufficiently complete round strokes or matching fragments. Uncertain circular geometry stays as linework.

Smooth curves & preserve small details

Enabled by default. Applies a light, bounded raster-noise filter and reduces simplification error for small features. Junction endpoints and sharp corners are protected. Reconvert to apply a change. Smoothed curves usually remain polylines; this does not create new ARC or spline entities.

Straighten lines

Reduces small scanning distortions using best-fit lines. Optional orthogonal snapping affects only nearly horizontal or vertical lines; keep it off for drawings with intentional slopes.

Hatch recognition

Detects repeated line patterns inside reliable closed regions and creates CAD HATCH entities. Tiny border gaps can be repaired automatically; larger gaps need manual selection.

Detect dashed lines

Detects DASHED, HIDDEN, CENTER, PHANTOM and DASHDOT patterns. Review the reconstructed patterns and per-sheet override under Layers; classification describes visible rhythm rather than engineering meaning.

Text and annotation options

Export recognized text (OCR) creates editable text. Separate controls find dimensions, remove detected text, or remove matched dimensions and labels. Text detection can run even when text export is off. PDF-XChange trial-overlay filtering remains targeted and may miss other watermarks.

07 / LINE PATTERNS

Recognize center, phantom and dash-dot lines

DASHED / HIDDEN

Regular dashes; shorter marks may be classified as HIDDEN. That classification does not establish which objects are hidden.

CENTER

Repeating long-short strokes. The detector can join small collinear junction fragments and needs at least two visible cycles.

PHANTOM

A repeating long-short-short pattern.

DASHDOT

Repeating long-dot marks. DXF uses a zero-length dot element; dots erased by speckle cleanup or lost at low resolution cannot be recovered reliably.

Enable Detect dashed lines in Convert and reconvert. Review the counts and patterns in Vectors only. Under Layers → Detected linetypes, choose Auto or a sheet-wide override. A few clipped marks, irregular spacing, merged text or heavy intersections may remain as ordinary linework. Crossing perpendicular geometry stays separate.

08 / ANNOTATION CLEANUP

Keep text from becoming linework

Choose these options before conversion, then reconvert the sheet. Detection and text export are separate choices.

Export recognized text (OCR)

Locates scanned lettering, masks its raster strokes and exports editable CAD TEXT. Recognized native PDF text can also become editable text. Check every reading.

Remove detected text (no text export)

Runs local OCR to locate lettering, masks detected strokes and omits both OCR and native text entities. Detected labels remain available internally for dimension QA. Missed text can still be traced as linework.

Find dimensions during conversion

Enabled by default. Supplies recognized labels to Dimension review even when OCR text export is off. This setting alone does not remove raster lettering.

Remove matched dimensions & labels

Removes eligible matched baselines, their witness lines and labels. Unmatched notes, detached arrowheads, shared chain baselines, leader-linked geometry, inferred readings and low-confidence matches can remain. Inspect the cleanup result before export.

What needs reconversion?

Recognition, cleanup and curve-smoothing changes require reconversion. Layer names, recognized-group linetype overrides, text height and plot scale apply to the next export without reconversion. Original imported files are unchanged; reconversion rebuilds geometry, so finish it before manual hatch or CAD repairs.

09 / QUALITY

What becomes editable CAD?

The vector preview shows the reconstructed CAD geometry, not just a processed black-and-white image. Recognition is still experimental.

LINE / LWPOLYLINE

Traced centerlines and path geometry

CIRCLE

Fitted center and radius

HATCH

Diagonal, crosshatch or solid fill

LINETYPE

DASHED, HIDDEN, CENTER, PHANTOM and DASHDOT

TEXT

Recognized text and dimension labels in Simplex

Review every sheet

Look for missing lines, duplicate traces, open intersections, misidentified dashed patterns, circular details that should be arcs, and incorrect hatch boundaries. Use AutoCAD or Civil 3D to validate before engineering use.

10 / REPAIR TOOLS

Repair a hatch boundary

For sections with damaged or missing hatch borders, the app can create a manually bounded native HATCH without reconverting the entire source sheet.

  1. Convert the sheet first. Open Review & scale → Hatch editor in Studio, or the manual hatch controls on the classic Review ribbon.
  2. Choose Use source pattern, Diagonal lines, Crosshatch, or Solid fill.
  3. For a manually chosen line pattern, specify its angle and spacing in processed pixels. Start near the spacing visible in the original scan.
  4. Click Draw hatch boundary and select three or more corners on the drawing. Use the wheel to zoom or hold Space and drag to pan.
  5. Click Finish hatch or press Enter. Use Undo point while drawing or Undo hatch afterward to revert the most recent manual addition.
Replace matched source strokes

This option is off by default. Enable it only if the region contains true hatch strokes that should be removed from the remaining geometry. Otherwise the original strokes can remain behind the newly created HATCH.

11 / CAD CLEANUP

Repair disconnected and duplicate linework

VecBuilt v0.8 includes a non-destructive, review-first tool to improve the connectivity of reconstructed CAD geometry after conversion.

01

Scan the reconstructed drawing

Convert a sheet and choose the Repair ribbon tab. Select Scan geometry. Default maximum gap: 3 source pixels, adjustable from 0.2 to 25. The scan analyzes the exported linework, not the original PDF pixels.

SCAN
02

Inspect highlighted suggestions

Select an issue in the Geometry repair drawer. The canvas centers the problem; amber shows the current line segments and cyan indicates the replacement geometry. Suggestions cover identical duplicates, small collinear gaps and candidate trim/extend intersections.

REVIEW
03

Select and apply multiple repairs

Check the boxes beside the suggestions you want, then choose Apply selected (N). Select visible checks the current filtered list; Clear selection unchecks everything. Selection persists across filters, and all checked repairs appear in the overlay. Review angled intersections before including them. Apply low-risk remains a separate action for near-identical duplicates and tiny aligned joins.

REPAIR
04

Undo, redo and compare

Use the ribbon Undo and Redo actions to compare before/after geometry. One batch is one undoable transaction. Overlapping or stale suggestions are skipped and reported; inspect the refreshed list before trying again. Rescanning or switching sheets clears selection. Up to 20 repair transactions are retained per sheet while it stays in the browser. The cleaned geometry is used in both the vector preview and the DXF export.

VERIFY
05

Deliver the cleanup audit

Batch ZIP exports include a JSON report in repair-QA and accepted repair counts in QA-manifest.json. Re-check dimension QA, endpoints and intersections in Civil 3D or AutoCAD after any topology edit.

EXPORT
Important safety limits

These are geometry-based suggestions, not guarantees of design intent. Intentional gaps, utilities, symbols, drafting conventions and dimension leaders can resemble cleanup errors. VecBuilt never silently applies uncertain fixes. Circles, hatches, curved polylines, text and recognized dash patterns are excluded from this repair stage. Finish hatch corrections before applying CAD repairs, because rebuilding hatch classifications changes the underlying geometry. Dense sheets may exceed the capped review list.

12 / DELIVERY

Layers and export

Use the Layers tab to name the linework, text, and hatch layers. You can choose a drawing discipline preset and override all detected pattern groups on that sheet to DASHED, HIDDEN, CENTER, PHANTOM or DASHDOT. This changes already recognized groups; it does not classify unrecognized fragments.

DXF

Download DXF

Exports the selected converted sheet as editable CAD entities. Studio also provides a quick DXF button in the header after conversion.

ZIP

Batch ZIP

Downloads DXFs for completed sheets, dimension/repair QA reports when available, and QA-manifest.json with calibration, plot scale, text style, cleanup, recognition and integrity diagnostics. Colliding sheet names receive unique filenames; QA sidecars follow those names.

Checks before download

Single and ZIP exports check required DXF sections and tables, layer plot-style references, handles, entity structure and finite coordinates. Empty or invalid output is blocked. An unanswered sheet-scale question blocks that sheet’s export; one invalid sheet stops the batch ZIP download. These checks do not certify Civil 3D compatibility or engineering accuracy.

DXF, not DWG

Native DWG output and intelligent Civil 3D objects such as alignments, surfaces, and pipe networks are not supported. Open the DXF in AutoCAD or Civil 3D and save a DWG there if required.

13 / QUESTIONS

Troubleshooting

My converted drawing is missing thin lines. What should I change?

Try 200 DPI instead of 150 DPI, then Adaptive threshold if the source is faded. Reduce speckle cleanup and the minimum line length cautiously. Reconvert and compare in Overlay and Vectors only.

Why are some curved objects made of segments?

Enable Convert → Smooth curves & preserve small details and reconvert. Small radii receive finer simplification so they are less faceted. A curve may still be a smoothed polyline: only sufficiently supported circles become CIRCLE entities. Increase source resolution when the curve spans too few pixels, and verify the shape in CAD.

Why did a dashed utility line become a hidden line?

The classifier recognizes a pattern of marks, not the engineering meaning. Use the detected linetype override in Layers for the selected sheet, then verify the result in CAD.

Why didn't my hatch become a HATCH entity?

The automatic detector needs a reliable closed boundary and consistent repeated strokes. For incomplete section borders, use Review & scale → Hatch editor (Studio) to select a polygon and choose a pattern.

The scale is wrong after exporting. What should I check?

Confirm you selected the correct units, clicked the exact known endpoints, and measured a substantial distance. Recalibrate the sheet and check a second independent dimension in CAD. Calibration does not supply survey coordinates.

Why is a large PDF taking so long?

Large engineering sheets are processed tile by tile. Choose 150 DPI first, crop to the required drawing area, and disable Export recognized text (OCR), Find dimensions during conversion, Remove detected text (no text export), and Remove matched dimensions & labels if you want to avoid OCR completely. Any of these options can require OCR. Multiple orientations increase processing time; high DPI also costs CPU and memory.

Dimensions are not being found. What should I check?

Enable Find dimensions during conversion and reconvert. Check rotated labels and fractions in the Dimensions drawer; OCR can confuse digits such as 2 and 7. Review Original OCR, correct the label, and pick endpoints manually when needed. Leader and chain associations are provisional.

Text is still showing up as lines. Why?

Enable Remove detected text (no text export) to omit detected lettering, or Export recognized text (OCR) to replace it with editable TEXT, then reconvert. Neither option can remove text that detection misses. Use higher-quality input and compare against Original.

My 0.10-inch text is too large or too small.

Verify CAD units, the selected sheet’s plot ratio and the scale used when plotting in CAD. The import question does not calibrate geometry. Use Layers → Set sheet scale and export again; for 1″ = 20′ use 1:240, not 1:20.

Export is blocked, or Civil 3D reports a DXF table error.

Answer each sheet’s scale question first. For an integrity error, note the export message and sheet name. Refresh the app after an update and create a new DXF; older downloads retain their original defects. If CAD still rejects the new file, retain the exact error and line number and provide the failing DXF privately for inspection. A clean parser check does not guarantee acceptance by every CAD importer.

Can I export a DWG or Civil 3D surface?

Not directly. Export DXF, open and check it in AutoCAD or Civil 3D, and save as DWG if needed. The app does not create parametric Civil 3D objects.

Does the converter work offline?

Conversion runs in your browser after the required code has loaded, but the app and some dependencies are hosted externally. Initial loading and OCR language-model downloads can require a network connection. Offline availability is not guaranteed.

14 / SECURITY

Privacy and limitations

The converter is designed to process files locally in the browser. No application endpoint uploads your selected PDF, image, or generated DXF for conversion.

Your drawing processing stays local

Libraries and OCR models can still be downloaded over the internet. Avoid adding confidential project files to public GitHub issues, shared links, or screenshots.

VecBuilt is an experimental drawing-reconstruction tool. Source quality, print scaling, skew, line joins, OCR, and recognition heuristics affect accuracy. The output is not survey-georeferenced, engineering certified, or a substitute for professional CAD review.
